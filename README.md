# 2D Pixel Sandbox (Terraria-Style Prototype)

A lightweight 2D tile-based sandbox game built with HTML5 Canvas and Vanilla JavaScript.

## Features
- **Procedural World Generation**: Random surface elevation and trees.
- **2D AABB Physics**: Gravity, jumping, and tile collision detection.
- **Mining & Building**: Break and place blocks within the player's reach radius.
- **Viewport Culling**: Optimized rendering that only draws visible tiles on screen.

## Controls
- **A / D** or **Left / Right Arrows**: Move
- **W / Space**: Jump
- **Left Click**: Mine block
- **Right Click**: Place block
- **Number Keys (1 - 4)**: Select block type (Dirt, Grass, Stone, Wood)

## How to Run Locally
Clone the repository and open `index.html` in any web browser.
